# 右侧目录按「节」上色（2.2.1）

- 日期：2026-09-17
- 状态：已实施并通过验证
- 范围：`src/components/TOC.astro`（文章右侧粘性目录，宽屏 ≥1440px 才显示）

## 1. 背景

目录项来自 Markdown 的多级标题（只取 2 / 3 级）。用户反馈：**不同层级的标题几乎分不出来** ——
当时两者的差别只有字号（0.8125rem / 0.78125rem，差 0.5px）、缩进，以及左侧那条用于显示阅读进度的
细色条；而色条用的是 `bg-border`，在浅色主题下几乎等于底色，等于没有。用户的诉求是"加颜色，比如彩虹配色"。

## 2. 结论

### 2.1 色相按「节」分配，而不是按层级

```
节 = 目录里最浅的那一级
hue(第 n 节) = (202 + n × 60) % 360
```

- 文章用 `##` 分节时，一个二级标题开一节，它的三级子标题沿用同一色相；
- 有的文章通篇只有 `###`（例如《ArchLinux 安装指南》23 条全是三级标题），
  那就每条自己算一节 —— 否则整列会是同一个颜色，用户的问题原样还在。
- 202 起手（主题蓝的色相），每节 +60°，正好绕一圈：
  蓝 → 紫 → 品红 → 橙 → 黄绿 → 青。

于是侧栏同时表达两件事：**文章分成几节**（颜色在换）、**哪几项属于同一节**（同色相 + 缩进）。

### 2.2 层级差异用"饱和度 + 字重 + 缩进"补足

| 目录项                | 文字色                             | 字重 | 缩进 | 左侧色条            |
| :-------------------- | :--------------------------------- | :--- | :--- | :------------------ |
| 节（最浅一级）        | `hsl(hue 62% 40%)`                 | 500  | 无   | `hsl(hue … / 0.55)` |
| 子项（更深一级）      | `hsl(hue 34% 46%)`（同色相去饱和） | 400  | 1rem | `hsl(hue … / 0.32)` |
| 当前小节（is-active） | 节的颜色 + 加粗 600                | 600  | —    | 进度填充用同色相    |

深色主题另给一组更亮的值（`hsl(hue 76% 72%)` / `40% 70%`），和分类圆点、标签药丸用的是同一套
「浅色 62%/41%、深色 78%/72%」的换算思路。左侧那条色条既是本节的标识，也继续承担阅读进度：
底色是色相的半透明版，填充是同一色相的实色。

颜色一律用 `hsl()` 直接算，不用 `color-mix` —— 目录项有几十条，一旦浏览器不支持 `color-mix`，
`var(--x)` 里塞一个非法值会让整条 `color` 声明失效（颜色退化成继承），不值得为它冒这个险。

## 3. 取舍

| 决定                                        | 理由                                                                | 被放弃的方案                                          |
| :------------------------------------------ | :------------------------------------------------------------------ | :---------------------------------------------------- |
| 色相按节（+60°/节）而不是按层级（固定两色） | 一节一色才有"彩虹"，也让"谁属于谁"一眼可见；层级仍由深浅与字重表达  | 二级一色、三级一色（只有两个颜色，长文章更单调）      |
| "节"取目录里最浅的一级                      | 通篇 `###` 的文章（仓库里有）不会整列一个色                         | 固定按二级标题分节（这类文章会全是同一个颜色）        |
| 子项沿用同色相去饱和，而不是换一个色相      | 同色相 = 有亲缘关系，配合缩进读得出层级；换色相会让"节"的边界变模糊 | 子项用色相 +30° 的邻近色                              |
| 每节固定 +60°，不按节数均分                 | 相邻两节的色差稳定在 60°（可辨），长列表里第 7 项才会与第 1 项同色  | 按节数均分（23 节的列表里相邻色差只剩 15°，糊成渐变） |
| 当前项用"加粗 + 同色淡底"，不再改颜色       | 所有项都已经带颜色了，靠颜色变化区分不出当前项                      | 当前项改用主题强调色（会与所在节的色相打架）          |
