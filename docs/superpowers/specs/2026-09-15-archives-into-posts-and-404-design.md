# 归档并入文章页 + 404 页面设计

- 日期：2026-09-15
- 状态：设计已确认，待实施
- 原则：**每个部分都要有用，没用就砍掉**

## 1. 背景

站点同时存在三个"找文章"的入口：`/posts/`（全部文章，分页卡片）、`/categories/`
（按栏目）、`/archives/`（按年/月分组）。前两个各有明确职能，归档的问题在于：

| 检查项 | 现状 |
| --- | --- |
| 站内引用 | 仅 header 里一个图标按钮（无文字），页脚 / RSS / 其它页面都没有链接 |
| 内容 | 与 `/posts/` 同一批 32 篇，只是分组方式不同 |
| 开销 | 每篇都渲染成完整卡片，单页 87 KB（`/posts/` 第一页 35 KB） |
| 独特价值 | 只有一条：按年份扫标题 |

结论：**砍掉"独立入口"，保留"按年份速查"这个唯一有用的视角**，把它并进文章页。

另外，站上还没有一个像样的错误页：现有 `404.astro` 只有 shruggie 表情和两个平级链接，
没有 `noindex`，也没有任何"猜你想去哪"的引导。

## 2. 非目标

- 不做多状态码错误页（403 / 500 等）。本站是纯静态输出，这类状态码由托管方产生，
  自定义不了；硬做只会得到假页面。
- 不引入 SSR / 适配器。
- 不做 404 的模糊匹配"猜你在找"、`?code=` 分流。
- 不改动 `/categories/`、`/tags/` 的既有结构。

## 3. 需求一：归档并入文章页

### 3.1 文章页双视图

`/posts/` 第一页顶部增加「卡片 / 时间轴」切换：

- **卡片视图**（默认）：现有分页卡片列表，每页 `SITE.postPerPage`（6）。
- **时间轴视图**：全部文章按「年 → 月」分组，每篇只占一行（`MM-DD` + 标题），
  年份带总数、月份用中文雅称（孟春 / 仲秋…）与小计，沿用现有水印年份的视觉语言。
  不重复渲染摘要与标签，所以比原归档页轻得多。
- 分页第 2 页起只有卡片视图（时间轴列的是全部文章，放在分页页上会误导）。

实现方式：两种视图都在构建时渲染进同一个页面，切换用少量原生 JS（渐进增强）：

- 没有 JS 时：切换条隐藏，两块内容依次显示（先卡片、后时间轴），页面不残废。
- 有 JS 时：显示切换条，只渲染当前选中的视图，切换不刷新、不请求。

### 3.2 入口与跳转

- header 里的归档图标按钮删除（`SITE.showArchives` 开关随之删除，已无用处）。
- `/archives/` 保留一个跳转页（`Astro.redirect`，与 `/music` → `/collection` 同款），
  并在 `vercel.json` 里加一条真正的 301（`/archives` → `/posts/`），让搜索引擎拿到
  正确的状态码。
- 导航最终形态：文章 / 分类 / 标签 / 收藏 / 追番 / 友链 / 关于我 + 搜索。

### 3.3 代码落点

| 文件 | 改动 |
| --- | --- |
| `src/utils/chineseMonth.ts` | 新增：中文月份雅称 + 数字转中文（从归档页迁出） |
| `src/layouts/Posts.astro` | 双视图外壳、时间轴渲染、切换脚本 |
| `src/pages/archives/index.astro` | 改为跳转页 |
| `src/components/Header.astro` | 删归档图标与 `archives` 导航态 |
| `src/config.ts`、`src/types.ts` | 删 `showArchives` |
| `vercel.json` | 加 301 |

## 4. 需求二：404 页面

单个页面，一屏内回答"发生了什么 + 怎么出去"：

1. 大号 `404` + 人话标题 + 一行说明（地址写错 / 文章改名 / 链接过期）。
2. 主按钮「回首页」+ 次按钮「搜索文章」——建立主次层级（现在两个按钮平级）。
3. 一行六个栏目 chips：给"我其实想找某类内容"的人兜底。
4. 一行小字「报告坏链」：`mailto:` 自动带上出错路径。
   静态页在构建时拿不到请求地址，所以由客户端 `location` 填充；无 JS 时显示兜底文案。
5. `<meta name="robots" content="noindex">`：错误页不该被收录。

实现方式：`Layout.astro` 增加 `noindex` 开关（渲染 robots meta），404 页传入。

## 5. 验证

1. `npm run lint`、`npm run build`（内含 `astro check`）全过。
2. 产物检查：`/posts/` 第一页含切换条与时间轴（32 篇全覆盖、年月分组正确），
   第 2 页不含时间轴；`/archives/` 是跳转页；header 无归档图标；
   `dist/404.html` 含 `noindex` 与栏目 chips。
3. 断网 `npm run preview` 目视：切换、深浅色、无 JS 降级。

## 6. 风险与兜底

| 风险 | 兜底 |
| --- | --- |
| 时间轴让文章页变长 | 只在第一页出现；每篇一行、不渲染卡片 |
| 切换脚本与 ClientRouter 软跳转冲突 | 用 `data-ready` 守卫 + `astro:after-swap` 重新初始化（与站内既有脚本同一套路） |
| 旧链接 `/archives/` 收不到 301 | 静态跳转页 + vercel.json 301 双保险 |
